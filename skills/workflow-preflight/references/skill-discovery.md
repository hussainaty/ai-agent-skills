# Skill discovery

Use this reference only when no installed skill covers a material part of the
task.

1. Define the exact missing capability and success signal. Do not search for a
   vague category such as "better output."
2. Check the public `skills.sh` leaderboard for established sources first, then
   perform a focused search. Keep at most three credible candidates.
3. Read each candidate's repository instructions before judging it. Assess the
   candidate as part of the proposed route: its task coverage, compatibility
   with selected skills, required tools or access, and duplicated work.
4. Verify source reputation, recent maintenance, install count, repository
   stars, documented permissions, and whether the capability already exists
   locally.
5. Recommend the best fit with its name, source, purpose, compatibility notes,
   and install command. Do not install it automatically. Installing a skill can
   add instructions, tools, or dependencies that affect later tasks.

Prefer official or well-maintained sources. Skip a candidate that asks for
credentials, broad system access, or opaque setup unless its benefit is clear
and the user explicitly wants that integration.
